# Local Agentに渡す実行依頼

`kon-cryo-02` (`labadmin`、GNOME 46.0 / X11) にClibor Lite X11 v0.1.0を導入し、ソースレビュー→依存確認→インストール→GUI実機受け入れテスト→不具合があれば修正・再試験まで実施してください。**作業仕様は README.md、受入基準は LOCAL_AGENT_VERIFICATION.md を正本としてください。**

最重要要件は「左右それぞれのCtrlキーを素早く2回押して履歴を表示」「普通のCtrl+C/Vなどを妨げない」「選択した履歴が元の入力位置に正しく貼り付けられる」「日時定型文 YYMMDD / YYMMDD-HHMM の動的展開」「必要に応じてCtrl+Alt+1/2直接入力」です。Cliborの軽さとポップアップ中心の操作感を維持してください。画面デザインではデジタル庁デザインシステムのアクセシビリティ、余白、フォーム構造を参考にしてください。

**順序**: 作業前に既存ソフトやショートカット競合をチェック。`bash scripts/diagnose.sh` と `PYTHONPATH=. /usr/bin/python3 -m unittest discover -s tests -v` を実行。ユーザーの許可を得た上で `bash install.sh`。Ctrl×2・履歴・検索・日時・自動貼り付けを複数アプリで検証。修正ごとに再試験し、最終的に PASS/FAIL 一覧、RSS/CPU、実行した変更、再現方法を報告。

**注意**: 既存のGNOMEカスタムショートカットを消さない。直接キーの登録はユーザー同意後に `scripts/gnome-shortcuts.py install`。クリップボード内容や秘密情報をログに収集しない。単体テストが通っていてもGUI/XRecordの動作確認が済むまでは「導入完了」としない。P0不具合が残る場合は自動起動を無効化して安全に停止し、原因と修正提案を提示してください。
