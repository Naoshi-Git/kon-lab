# 大阪大学 学内連絡バス検索 Web App 実装計画・仕様

## 1. 目的

大阪大学の豊中・箕面・吹田キャンパス間を走る学内連絡バスについて、公式時刻表を直接読み解かなくても、現在地・日時・希望条件から利用できる便を検索できるスマートフォン向けWebアプリを提供する。

操作感は一般的な乗換検索サービスを参考にするが、学内連絡バス固有の以下の条件を正確に扱う。

- 3キャンパスと複数の実停留所
- 豊中―吹田の直行便
- 箕面経由便
- 箕面止まり／箕面始発便
- 授業期間中の平日のみという運行条件
- 大学指定の長期休業・行事運休日
- 往路到着後に利用できる復路

## 2. UI方針

提示された白基調・グリーンアクセントのモバイルUIをデザインの正本とする。

採用する要素：

- ホーム上部に「次の便」を大きく表示
- 角丸カードと余白を用いた情報階層
- 下部固定ナビゲーション
- ホーム／ルート検索／時刻表／設定の4画面
- 現在地、発車までの時間、発着時刻を優先表示
- 検索結果を比較しやすいカード形式

除外する要素：

- 購入・予約機能
- 混雑予測
- 車両位置・遅延・満席のリアルタイム表示
- 根拠のない通知機能

## 3. 実装済み機能

### 3.1 ホーム

- 現在時刻を基準とした次便表示
- 発車時刻、到着時刻、所要時間
- 直行／箕面経由／乗換なしの区別
- 直近3便
- 出発キャンパスの手動選択
- 位置情報を利用した最寄りキャンパス推定
- 行き先のワンタップ切替
- 最近検索したルートの再利用

### 3.2 片道検索

- 出発キャンパス
- 到着キャンパス
- 日付
- 出発時刻指定
- 到着時刻指定
- 豊中―吹田の直行便のみ
- 吹田の詳細停留所指定
  - 工学部前
  - 人間科学部前
  - コンベンション前
- 発着停留所、所要時間、便ID、経由種別の表示

### 3.3 往復検索

- 往路候補ごとに復路候補を組み合わせる
- 往路到着後の滞在時間を指定
  - 45分
  - 60分
  - 90分
  - 1コマ（105分）
  - 2時間
- 当日中に復路がない場合は次の通常運行日も検索
- 往路と復路を1組のカードとして表示

### 3.4 運行日判定

- 月曜日から金曜日のみ
- 国民の祝日を除外
- 大学公式PDFの運休日を除外
- 最終便後は次の通常運行日へ繰り越し
- 年度範囲外は対象外として案内
- 2026年5月1日の特別ダイヤ予定日は通常ダイヤへ混在させない

### 3.5 保存

サーバーやログイン機能は使用せず、端末の `localStorage` のみを使用する。

保存対象：

- 既定のキャンパス
- 最近使ったルート
- お気に入りルート

位置情報そのものは保存・送信しない。

### 3.6 時刻表

- 豊中・箕面 → 吹田
- 吹田・箕面 → 豊中

の2方向を切り替え、各便の停車停留所と時刻を表示する。

## 5. データモデル

UI上は3キャンパスを基本単位とする。

- `toyonaka`
- `minoh`
- `suita`

検索エンジン内部では実停留所を区別する。

- `toyonaka`：豊中地区
- `minoh`：箕面キャンパス前
- `suita_convention`：コンベンション前
- `suita_engineering`：工学部前
- `suita_human_sciences`：人間科学部前

各便は、停車する停留所だけを順序付きで保持する。

```js
{
  id: "E08",
  direction: "eastbound",
  stops: [
    { stopId: "toyonaka", time: "09:20" },
    { stopId: "minoh", time: "09:40" },
    { stopId: "suita_convention", time: "09:55" },
    { stopId: "suita_engineering", time: "10:00" }
  ]
}
```

公式表で `－` の停留所はnull時刻として残さず、停車列から除外する。これにより「通過」と「時刻不明」を混同しない。

## 6. 検索ロジック

### 6.1 出発時刻検索

1. 指定日の運行可否を判定
2. 出発・到着停留所を順番に通過する便を抽出
3. 指定時刻以降の出発便に限定
4. 直行条件を適用
5. 発車時刻順に返す
6. 便がなければ次の通常運行日を検索

### 6.2 到着時刻検索

1. 指定日の運行可否を判定
2. 指定時刻以前に到着する便を抽出
3. 出発時刻が遅い順に返す

到着時刻検索では、指定日から別日への自動繰り越しは行わない。

### 6.3 直行判定

豊中―吹田間の「直行」は、乗換の有無ではなく、選択区間内に箕面キャンパス前を含まない便とする。

### 6.4 往復検索

1. 往路候補を検索
2. 往路到着時刻に滞在時間を加算
3. その時刻以降の復路を検索
4. 往路・復路を組にして表示

実行コマンド：

```bash
node --test campus-bus/tests/search-engine.test.mjs
```

実装時点で以下の7ケースを通過済み。

- 豊中→吹田の直行便
- 箕面経由便の判定
- 直行便絞り込み
- 到着時刻検索
- 夏季運休日から次の運行日への繰り越し
- 往復検索
- 人間科学部前からの検索

加えて、JavaScript構文確認とHTMLパースを実施する。

## 9. MVP対象外・将来検討

公式または運行事業者から安定したデータが提供される場合に限り、次を再検討する。

- 当日の運休・大幅遅延表示
- 車両位置
- 満席・混雑情報
- 公式データ更新の自動検知
- 翌年度時刻表の自動切替

根拠データのない予測値は表示しない。
